# Cloud Cost Attribution By Agent

This example simulates cloud resource usage events, each tagged with an 'agent' (e.g., project or team). It then processes these events to calculate and display a cost breakdown per agent, demonstrating how granular cost attribution provides visibility beyond a simple total spend.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
